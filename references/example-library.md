# Example library

Every message in a `text` block on this page satisfies the [Complete Commit Contract](agent-commit-protocol.md) and passes `scripts/lint-commit.py`. They are illustrative, written for realistic situations, not copied from real projects. Adapt the trailer to the one your repository records.

## Features

```text
feat(auth): add passkey sign-in for returning users

Password resets were the top support request last quarter. Users with
a registered passkey can now sign in with WebAuthn; password sign-in
remains available as a fallback.

Breaking: none
Refs: #214
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
feat(api): add cursor pagination to the orders endpoint

Large accounts timed out when listing orders with offset paging.
GET /orders now accepts `cursor` and `limit` and returns `next_cursor`;
offset parameters keep working unchanged.

Breaking: none
Refs: #377
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
feat(cli): add --dry-run flag to the deploy command

Operators asked to preview a deploy before applying it. The flag
prints the planned changes and exits with status 0 without
contacting the target environment.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

## Fixes

```text
fix(cache): evict stale entries when a record is deleted

Deleted products kept appearing in search for up to an hour because
the cache was only invalidated on update. Delete events now evict the
key immediately.

Breaking: none
Fixes: #402
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
fix(api): return 400 instead of 500 for malformed emails

Invalid email input reached the database layer and surfaced as an
internal error. Validate the format at the handler and return a 400
with a field-level message.

Breaking: none
Refs: #129
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
fix(ui): keep focus inside the modal when tabbing

Keyboard users could tab behind an open dialog, which fails WCAG 2.4.3.
Trap focus within the modal and restore it to the trigger on close.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
fix(deps): bump undici to 6.21.1 for header parsing fix

The previous version mis-parsed folded response headers from one of
our upstream providers. This patch release contains the upstream fix
and no API changes.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

## Performance, refactoring, and style

```text
perf(db): add composite index for order history queries

The order history page scanned the full orders table. An index on
(customer_id, created_at) cuts p95 latency from 820 ms to 45 ms in
the staging dataset.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
refactor(parser): extract token validation into a helper

The same validation logic was duplicated in three call sites and had
started to drift. Move it into validateToken() with no change in
behavior, so the next fix lands in one place.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
style(api): apply prettier formatting to route handlers

The handlers predate the formatter config and produced noisy diffs in
every review. Formatting only; no logic or behavior changes.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

## Breaking changes

```text
feat(api)!: remove legacy v1 login endpoint

The v1 endpoint bypassed rate limiting and has been deprecated since
2.3, with no traffic in the last 90 days. Removing it closes the gap
and deletes the compatibility layer.

BREAKING-CHANGE: POST /v1/login is removed. Call POST /v2/sessions
  with the same credentials instead; see docs/migrate-v2.md.
Refs: #512
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
refactor(config)!: rename DB_URL to DATABASE_URL

Every other tool in our stack reads DATABASE_URL, and supporting both
names caused confusing precedence bugs. Read only the standard name.

BREAKING-CHANGE: DB_URL is no longer read. Rename the variable to
  DATABASE_URL in every environment before upgrading.
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
build(runtime)!: drop support for Node.js 18

Node 18 is end of life and blocks the move to native fetch streaming.
The engines field now requires Node 20.11 or later.

BREAKING-CHANGE: installing on Node 18 now fails. Upgrade to Node 20
  or 22 before updating this package.
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

## Monorepos and pairing

Support agents could not tell shipped orders from pending ones at a
glance. Render a colour-coded status badge using the shared Badge

Breaking: none

Co-Authored-By: Claude Code <noreply@anthropic.com>

```text
fix(@acme/http-client): retry idempotent requests on ECONNRESET

Load balancer rotations reset idle keep-alive sockets and failed GET
requests that were safe to repeat. Retry idempotent methods once with
jitter; POST requests still fail immediately.

Breaking: none
Co-Authored-By: Claude Code <noreply@anthropic.com>
```

```text
fix(checkout): round tax per line item instead of per order

Totals differed by one cent from invoices in some states because tax
was rounded once on the order total. Round each line as the invoicing
system does.

Breaking: none
Refs: FIN-482
Co-Authored-By: Jordan Lee <jordan.lee@example.com>
Co-Authored-By: Claude Code <noreply@anthropic.com>
```
